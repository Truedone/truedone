truedone

Checks whether a pull request's tests prove its change: red without it, green with it.

What truedone checks

truedone checks whether a pull request's tests prove its change: a test should fail without the change and pass with it.

Ways to use it

  • A pull request on this site: replace github.com with truedone.pages.dev in its address, as in truedone.pages.dev/Truedone/truedone-sandbox/pull/31.
  • The command line: npx truedone checks the branch you are on, and npx truedone <PR link> checks a pull request.
  • The GitHub App: github.com/apps/truedone sets one check run and at most one label on each pull request of a repository that installed it.
  • The Claude Code plugin: truedone for Claude Code, with /plugin marketplace add Truedone/truedone, then /plugin install truedone@truedone.
  • The MCP server: npx truedone mcp serves the check to an agent over the Model Context Protocol.

What each verdict and label means

For coding agents: /llms.txt says what truedone checks and how to run it.
