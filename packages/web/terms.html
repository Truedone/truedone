truedone

Checks whether a pull request's tests prove its change: red without it, green with it.

Terms

These terms cover the site at truedone.pages.dev, its token exchange, the GitHub App and the action.

  • truedone is pre-release software. Its code is licensed under Apache-2.0, and that licence governs the code.
  • The site, the token exchange and the app are offered free and as they are, with no warranty, in the same way the licence offers the code.
  • A verdict states what truedone observed about a change. It is not a review of the change, and it does not replace one.
  • Red-green on someone else's pull request executes that pull request's code on the machine where it runs. The CLI asks before it does so, and --docker runs it in a container.
  • truedone can change or stop at any time. You can uninstall the app or remove the action at any time. What happens to stored data then is in the privacy note.
  • How truedone reads and stores data is in the privacy note, and how to report a vulnerability is in the security policy.
